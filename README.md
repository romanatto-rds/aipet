# AI PET - Seu companheiro do futuro

## Sobre o projeto

O AI PET é um aplicativo futurista desenvolvido para representar uma plataforma de cuidados de um animal robótico. A proposta é imaginar como seria cuidar de um companheiro tecnológico no ano de 2046.

## Objetivo

Criar uma interface moderna, intuitiva e interativa que permita acompanhar as condições de um pet robótico, apresentando informações sobre alimentação, energia e humor.

## Funcionalidades

- Visualização do animal robótico LUNA.
- Painel de alimentação.
- Indicador de energia e bateria.
- Acompanhamento do humor do pet.
- Painéis informativos sobre os cuidados necessários.
- Área de atividades para carinho, brincadeiras e conversas.
- Interface adaptável para computadores e celulares.

*Os indicadores são demonstrativos e representam o conceito do aplicativo.*

## Tecnologias utilizadas

- HTML5 — Estrutura da interface.
- CSS3 — Estilização, identidade visual, animações e responsividade.
